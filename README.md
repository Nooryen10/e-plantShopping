# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery is an online shopping platform offering a wide selection of houseplants categorized by air-purifying, aromatic, and medicinal qualities.

### Application Features
- Landing page with background image and quick access.
- Interactive product gallery across multiple categories.
- Global cart state managed via Redux Toolkit.
- Real-time cart updates (item counts, sub-totals, totals).
